# Финансовый калькулятор

Финансовый калькулятор для расчета простых и сложных процентов, а также налогов.

## Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd financial_calc
```

2. Убедитесь, что у вас установлен uv:
```bash
pip install uv
```

3. Установите зависимости:
```bash
uv sync
```

## Запуск тестов

```bash
uv run pytest
```
